## Introduction
This section contains guidance for users transitioning from Microsoft Word 2010 to Microsoft 365 Word. It highlights the key differences, new features, and improved functionalities to help users adapt efficiently.

## What’s New in Microsoft 365 Word?
Compared to Word 2010, Microsoft 365 Word offers:
- Cloud Integration: Save and access documents from anywhere using OneDrive.
- Real-time Collaboration: Work simultaneously with colleagues on the same document.
- Modern Interface: A more streamlined and intuitive design.
- AI-powered Features: Tools like Editor, Dictation, and Smart Lookup.
- Regular Updates: New features and security updates without needing to install a new version.

# Cloud-Based Access & Storage (Onedrive Integration) 
Microsoft 365 Word allows users to save, access, and edit documents from the cloud.
To save the documents on to a Onedrive, follow these steps: 
1. Open Microsoft Word document.
2. Click **File** and then click **Save As**.
3. Choose OneDrive - Personal or OneDrive - [Your Organization].
4. Name your document and click **Save**.
5. Access the files from any device by logging into OneDrive (https://onedrive.live.com/).

## **2. Real-Time Collaboration & Co-Authoring**  
This feature allows multiple users to edit a document simultaneously.

### **Steps:**  
1. Open a document in **Microsoft 365 Word**.
2. Click on **Share** (top-right corner).
3. Enter the email addresses of collaborators.
4. Set permissions to **Can Edit** or **Can View**.
5. Click **Send**.
6. Collaborators can open and edit the document in real-time.

## **3. AI-Powered Writing Assistance (Microsoft Editor & Dictation)**  
Microsoft Editor offers grammar and style suggestions, while Dictation converts speech to text.

### **Steps to Use Microsoft Editor:**  
1. Open a document and start typing.
2. Look for underlined words (blue for style, red for spelling, green for grammar).
3. Right-click on the underlined word to see suggestions.
4. Click on **Accept Suggestion** or **Ignore**.

### **Steps to Use Dictation:**  
1. Click on **Home** > **Dictate**.
2. Speak clearly into your microphone.
3. Your words will appear as text in the document.
4. Click **Stop Dictation** when finished.

## **4. Modernized User Interface & Customization**  
Microsoft 365 Word provides a cleaner ribbon interface with Dark Mode support.

### **Steps to Customize the Ribbon:**  
1. Click on **File** > **Options** > **Customize Ribbon**.
2. Select the tools you want to add or remove.
3. Click **OK** to apply changes.

### **Steps to Enable Dark Mode:**  
1. Click on **File** > **Options** > **General**.
2. Under **Office Theme**, choose **Dark Gray** or **Black**.
3. Click **OK**.
