# VSH-450 publication source model

The public manual in `../index.html` is the controlled content source for the website. `scripts/build-vsh450-standalone.mjs` embeds the two stylesheets and produces the downloadable HTML from that same source. The documentation-quality workflow checks the output for drift, internal links, figure inventory, and part count.

The DITA files in this folder are a small topic-authoring prototype. They show the concept/task/reference separation, a reusable isolation prerequisite, and model effectivity with `@props`. The public HTML is not generated by a DITA processor; the prototype must not be described as a complete DITA publishing pipeline.

| Content type | Published topic | DITA prototype | Reuse or condition |

## Editorial control

- Use **pump** for the complete assembly, **motor** for the electrical drive, **bearing carrier** for the oil-containing support, and **seal cartridge** for the replaceable shaft seal.
- Give one action per numbered step. Use the imperative, a complete sentence, and a period. Put the location or component before the action when needed to prevent work on the wrong part.
- State prerequisites, tools, consumables, PPE, acceptance criteria, and records outside the numbered action list.
- Use SI units and a space between the number and unit. State the measurement point and operating condition with each limit.
- Put model and serial-number effectivity at the point of use. Do not rely on colour or a visual alone to communicate a condition.
- Cross-reference stable section, table, and figure numbers. Keep SVG titles and descriptions for nonvisual readers.
- Treat part numbers, torque values, wear limits, and service intervals as controlled data. Change impact review must update every linked task, figure, table, and output copy.
- Procedure wording follows the numbered-step, parallel-structure, complete-sentence conventions in the supplied Microsoft Manual of Style (4th edition, Chapter 6). Formal ASD-STE100 conformance requires a separate licensed editorial assessment.
